# [T005] Не раскрывать отсутствие настройки аутентификации устройств
- приоритет: средний
- статус: открыто
- теги: security, server

## Описание
`require_device_key` при отсутствии или некорректной `MTA_DEVICE_KEYS` отвечает 503 с `detail="Device authentication not configured"`. Это раскрывает состояние конфигурации наружу.

Что сделать: отвечать обобщённой ошибкой без деталей (500/503 с нейтральным текстом), подробности оставить в логе. То же проверить для `_operator_config` (`Operator authentication not configured`).

Критерий готовности: в ответе нет упоминаний конфигурации, причина видна в логе.
