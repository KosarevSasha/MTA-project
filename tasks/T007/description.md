# [T007] Документировать (или реализовать) отзыв операторских сессий
- приоритет: средний
- статус: открыто
- теги: security, auth, docs

## Описание
Токен сессии самодостаточный: `/logout` лишь удаляет cookie, украденный токен остаётся валидным до 8 часов.

Что сделать (на выбор):
- задокументировать ограничение и способ массового отзыва (смена `MTA_SESSION_SECRET`);
- или хранить идентификаторы сессий (nonce) в БД и проверять их, чтобы `/logout` реально отзывал сессию.

Критерий готовности: поведение описано в README либо отзыв реализован и покрыт тестом.
