# [T015] Вынести HTML логина и дашборда из Python-файла
- приоритет: низкий
- статус: в процессе
- теги: refactor, server, frontend

## Описание
`LOGIN_HTML` и `MONITOR_HTML` (около 100 строк) лежат строками в `mta_server.py`, подстановка ошибки сделана через `.replace("ERROR_PLACEHOLDER", ...)`.

Что сделать: переместить в `templates/` или статические файлы пакета (проверить, что они попадают в сборку `uv_build`), для сообщения об ошибке использовать шаблонизацию с экранированием.

Критерий готовности: страницы отдаются как прежде, `mta_server.py` не содержит HTML.
