## Описание
`get_device` возвращает 200 с `{"status": "not_found"}`, а `monitor_device` — корректный 404. Поведение нужно выровнять.

Что сделать: бросать `HTTPException(404)`, обновить README (п. про `not_found`) и проверки эмулятора, если они на это опираются.

Критерий готовности: оба эндпоинта возвращают 404 для неизвестного устройства.
