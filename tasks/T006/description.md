# [T006] Сделать ограничение попыток входа устойчивым к прокси и многопроцессности
- приоритет: высокий
- статус: открыто
- теги: security, auth, deploy

## Описание
`LOGIN_ATTEMPTS` — словарь в памяти процесса с ключом `request.client.host`:
- за обратным прокси (nginx) все клиенты имеют один адрес, пять неудач блокируют вход всем, включая владельца;
- при нескольких воркерах лимит умножается;
- записи не удаляются целиком, словарь растёт.

Что сделать:
- определить реальный IP через `--proxy-headers` и `--forwarded-allow-ips` uvicorn (или доверенный заголовок) и описать настройку в README;
- периодически чистить пустые очереди;
- до выкладки на VPS решить, где хранить счётчики (SQLite-таблица или внешнее хранилище), либо явно зафиксировать ограничение «один процесс».

Критерий готовности: решение принято и задокументировано, пустые ключи не накапливаются.
