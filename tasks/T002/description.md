# [T002] Исправить формат логирования в receive_event
- приоритет: высокий
- статус: открыто
- теги: bug, server, logging

## Описание
В `mta_server.py` (обработчик `sqlite3.Error` в конце `receive_event`) вызов `logger.exception("Event database failure: ?", event.event_id)` использует `?` вместо `%s`. `logging` не подставит аргумент и выведет ошибку форматирования вместо причины сбоя.

Что сделать: заменить на `"Event database failure: %s"`. Заодно проверить остальные вызовы `logger.*` на тот же дефект.

Критерий готовности: при искусственной ошибке БД в логе виден `event_id`.
