# [T014] Не выставлять PRAGMA journal_mode = WAL на каждом соединении
- приоритет: низкий
- статус: открыто
- теги: refactor, server, db

## Описание
`get_db_connection` выполняет `PRAGMA journal_mode = WAL` при каждом запросе. Режим WAL постоянный и записывается в файл БД, повторять его не нужно.

Что сделать: выставлять WAL один раз при инициализации БД (в скрипте инициализации или при старте приложения), оставив `foreign_keys = ON` на каждом соединении.

Критерий готовности: режим WAL включён после инициализации, лишних PRAGMA в горячем пути нет.
