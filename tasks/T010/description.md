# [T010] Исправить TypeError при не-ASCII логине
- приоритет: срочно
- статус: открыто
- теги: bug, auth, server

## Описание
В `login` вызов `hmac.compare_digest(username, "admin")` принимает `str`, но выбросит `TypeError` для строк с не-ASCII символами и вернёт 500 вместо 401. Пример: `username=админ`.

Что сделать: сравнивать байты — `hmac.compare_digest(username.encode("utf-8"), b"admin")`. Заодно проверить, что неверный логин по времени не отличается от неверного пароля (сейчас `_verify_password` пропускается при неверном логине из-за `and`).

Критерий готовности: логин с кириллицей возвращает 401; добавлен тест.
