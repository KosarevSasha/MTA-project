# [T011] Убрать mta.db из git и игнорировать файлы SQLite
- приоритет: высокий
- статус: открыто
- теги: chore, git, security

## Описание
Файл `mta.db` закоммичен как временная мера и содержит данные устройств и остатки. В `.gitignore` нет `*.db`, а режим WAL создаёт `*.db-wal` и `*.db-shm`, которые легко закоммитить случайно.

Что сделать:
- добавить в `.gitignore`: `*.db`, `*.db-wal`, `*.db-shm`;
- удалить `mta.db` из индекса (`git rm --cached mta.db`);
- добавить команду/скрипт инициализации БД из `mta_schema.sql` и `mta_errors.sql` и описать в README;
- решить, нужно ли чистить историю (если база содержала реальные данные).

Критерий готовности: `git ls-files | grep db` пусто, новая база создаётся одной командой.
