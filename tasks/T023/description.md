# [T023] Добавить автоматические тесты (pytest + TestClient)
- приоритет: высокий
- статус: открыто
- теги: testing, server

## Описание
Тестов нет. Проверки в `check` требуют запущенного сервера и ключа.

Что сделать: добавить `pytest` в dev-зависимости, тесты на `fastapi.testclient.TestClient` с временной SQLite-базой, создаваемой из `mta_schema.sql` и `mta_errors.sql`. Покрыть как минимум:
- идемпотентность по `event_id` и конфликт `session_id`;
- откат транзакции при нехватке остатка (`UNLOAD`);
- жизненный цикл ошибок (`ERROR_SET`/`ERROR_CLEAR`, `active_error`);
- аутентификацию устройств и оператора, лимит попыток входа;
- валидацию `created_at` без часового пояса.

Критерий готовности: `uv run pytest` проходит, тесты запускаются в CI.
