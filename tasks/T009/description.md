# [T009] Ограничить размер и длину полей входящих событий
- приоритет: средний
- статус: открыто
- теги: security, server, validation

## Описание
`DeviceEvent.data: dict` принимает любой JSON, он целиком пишется в `events.data` и `device_errors.details`. Поля `event_id`, `device_id`, `session_id`, `product_id`, `error_code` не ограничены по длине. Устройство с валидным ключом может забить БД.

Что сделать:
- задать `max_length` для строковых полей (pydantic `Field`);
- ограничить размер `data` (число ключей/сериализованный размер);
- описать лимит тела запроса на уровне прокси в README.

Критерий готовности: слишком большие запросы отклоняются с 4xx; добавлены тесты.
