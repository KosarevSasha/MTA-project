# [T019] Эмулятор: запоминать для повтора только успешную продажу
- приоритет: средний
- статус: открыто
- теги: bug, emulator

## Описание
В `vending_emulator.py` `handle_key` для клавиш 1–4 возвращает `result[0]` (тело запроса) независимо от статуса ответа. Если сервер ответил 400, клавиша `6` повторит неудавшуюся продажу, а не последнюю успешную.

Что сделать: запоминать тело только при `status == 200`.

Критерий готовности: после отклонённой продажи клавиша 6 повторяет предыдущую принятую.
